# site-kit 1.0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release site-kit 1.0.1. Flag notes become tooltips (shown on hover, keyboard focus or tap) so flagged text flows naturally. Add fixes found while adopting the kit on the first site.

**Architecture:** Small, independent changes to the existing modules. Flags gain `tabindex="0"` in show mode and their note becomes an absolutely positioned tooltip in `review.css`. The plugin's transform adds the review stylesheet only to pages that contain kit markup. Guidance, skill, doctor, hook, settings template and config get targeted fixes.

**Tech Stack:** As 1.0.0: Node 22+, Eleventy 3 (peer), playwright-core, `node:test`.

## Global Constraints

- The repository is **public**: no names of people, clients or businesses, no real domains, phone numbers or IDs. Guidance describes roles, never individuals or their skills.
- Cross-platform: Node scripts only, paths via `path`/`fileURLToPath`, child processes via `process.execPath`.
- Install packages only with npm 10 (`npx -y -p npm@10.9.9 npm install …`). This release adds no packages.
- Hidden output (`hide` mode) must stay free of any flag markup, note text or `tabindex`.
- Work on branch `release-1.0.1` from `main`. Commits use the repo's configured noreply identity, with a `Co-Authored-By:` trailer naming the model that wrote the commit. Never push `main`.
- The contract tests in `test/contract.test.js` must keep passing: the demo site passes every check, and each broken copy fails only its own check.

Implement in `src/commands/doctor.js`:
```js
export function decisionAge(date, now) {
  const days = Math.floor((now - new Date(`${date}T00:00:00Z`)) / 86400000);
  if (days < 0) return "in the future";
  if (days === 0) return "today";
  return days === 1 ? "1 day ago" : `${days} days ago`;
}
```
