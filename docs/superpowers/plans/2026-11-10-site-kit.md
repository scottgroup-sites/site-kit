# site-kit v1.0.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and release site-kit v1.0.0: an Eleventy plugin plus a `site-kit` CLI that gives every site the same checks, content-review flags, Claude Code rules and CI.

**Architecture:** Plain ESM JavaScript, no build step. `src/config.js` validates each site's `site-kit.config.js`. `src/eleventy/plugin.js` renders flags and photo placeholders in `show`/`hide`/`fail` mode and writes `CONTENT-REVIEW.md`. `src/runner/` builds a site into a temp folder and runs the check modules in `src/checks/` over every built page. `src/commands/` implements `test`, `review`, `add-photo`, `sync`, `doctor` and `hook`; `bin/site-kit.mjs` dispatches to them. `templates/` holds the files `sync` writes into site repos.

**Tech Stack:** Node 22+, Eleventy 3 (peer), linkedom, html-validate 11, playwright-core 1.65 + @axe-core/playwright 4.14 (system Chrome / Edge), sharp 0.35, `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-10-site-kit-design.md`

## Global Constraints

- This repository is **public**: no names of people, clients, businesses or sites; no real domains, phone numbers, addresses, form keys or analytics IDs. Examples use `example.com`, `example.org` and `(555) 01xx` numbers. Guidance describes roles ("content editor", "developer"), never individuals or their skills.
- Cross-platform (macOS, Windows, Linux): no shell built-ins in scripts; paths via `fileURLToPath` and `path.join`; child processes via `process.execPath`, never `npx`, except where a shell is explicitly required and documented.
- Install packages with npm 10: `npx -y -p npm@10.9.9 npm install …`. Never commit a lockfile written by npm 11.
- `"type": "module"`, Node `>=22`, no build step, no `prepare` script.
- Check IDs exactly: `a11y`, `html`, `links`, `structure`, `consistency`, `performance`, `hosts`, `csp`, `readability`, `sitemap`, `sensitive-fields`.
- Default budgets exactly: `htmlPerPage: "60 KB"`, `pageTotal: "1200 KB"`, `imageFile: "300 KB"`, `cssTotal: "40 KB"`, `jsTotal: "30 KB"`.
- Flag types exactly: `CONFIRM`, `NEW`, `MADE UP`, `STOCK`. Photo aspects exactly: `1/1`, `4/3`, `3/2`, `16/9`, `21/9`, `3/4`, `2/3`, `4/5`.
- Messages shown to users are plain English and say how to fix the problem.
- Commit after each task with a message ending in `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```js
import { existsSync } from "node:fs";
import { join } from "node:path";
import { pathToFileURL } from "node:url";

export const CHECK_IDS = ["a11y", "html", "links", "structure", "consistency", "performance", "hosts", "csp", "readability", "sitemap", "sensitive-fields"];
export const HOST_TYPES = ["script", "stylesheet", "iframe", "img", "form"];
export const DEFAULT_BUDGETS = { htmlPerPage: "60 KB", pageTotal: "1200 KB", imageFile: "300 KB", cssTotal: "40 KB", jsTotal: "30 KB" };
const KNOWN_KEYS = ["site", "productionBranch", "previewPort", "claude", "flags", "footer", "fonts", "allowedHosts", "budgets", "sitemap", "htmlValidate", "exceptions"];

export class ConfigError extends Error {}

export function parseSize(value) {
  const m = /^(\d+(?:\.\d+)?)\s*(KB|MB)$/i.exec(String(value).trim());
  if (!m) return null;
  return Math.round(Number(m[1]) * (m[2].toUpperCase() === "MB" ? 1024 * 1024 : 1024));
}

const isObject = (v) => v !== null && typeof v === "object" && !Array.isArray(v);
const hasReason = (v) => typeof v?.reason === "string" && v.reason.trim().length > 0;

export function validateConfig(raw) {
  if (!isObject(raw)) throw new ConfigError("site-kit.config.js must export an object: export default { … }.");
  const problems = [];
  const warnings = [];

  for (const key of Object.keys(raw)) if (!KNOWN_KEYS.includes(key)) problems.push(`Unknown setting "${key}".`);

  const url = typeof raw.site?.url === "string" ? raw.site.url.replace(/\/$/, "") : "";
  if (!/^https:\/\/[^/\s]+$/.test(url)) problems.push('site.url must be the site\'s https origin, e.g. "https://www.example.com".');

  const productionBranch = raw.productionBranch ?? "main";
  if (typeof productionBranch !== "string" || !productionBranch) problems.push("productionBranch must be a branch name.");

  const previewPort = raw.previewPort ?? 8080;
  if (!Number.isInteger(previewPort) || previewPort < 1024 || previewPort > 65535) problems.push("previewPort must be a whole number between 1024 and 65535.");

  const care = raw.claude?.care ?? false;
  if (typeof care !== "boolean") problems.push("claude.care must be true or false.");

  const production = raw.flags?.production ?? "fail";
  if (!["fail", "hide"].includes(production)) problems.push('flags.production must be "fail" or "hide".');

  const footer = { text: raw.footer?.text ?? [], links: raw.footer?.links ?? [] };
  if (!Array.isArray(footer.text) || !footer.text.every((s) => typeof s === "string" && s)) problems.push("footer.text must be a list of text snippets.");
  if (!Array.isArray(footer.links) || footer.links.some((l) => typeof l !== "string" || !l.startsWith("/"))) problems.push('footer.links must be a list of paths like "/privacy/".');

  const fonts = raw.fonts ?? [];
  if (!Array.isArray(fonts) || !fonts.every((s) => typeof s === "string" && s)) problems.push("fonts must be a list of font family names.");

  const allowedHosts = raw.allowedHosts ?? [];
  if (!Array.isArray(allowedHosts)) problems.push("allowedHosts must be a list.");
  else allowedHosts.forEach((h, i) => {
    if (typeof h?.host !== "string" || !/^[a-z0-9.-]+$/i.test(h.host)) problems.push(`allowedHosts[${i}].host must be a host name like "cdn.example.org" (no https://).`);
    if (!Array.isArray(h?.types) || !h.types.length || !h.types.every((t) => HOST_TYPES.includes(t))) problems.push(`allowedHosts[${i}].types must list one or more of: ${HOST_TYPES.join(", ")}.`);
    if (!hasReason(h)) problems.push(`allowedHosts[${i}].reason must say why this service is approved.`);
  });

  const budgets = {};
  const budgetLabels = {};
  const rawBudgets = raw.budgets ?? {};
  for (const key of Object.keys(rawBudgets)) if (!(key in DEFAULT_BUDGETS)) problems.push(`budgets.${key} isn't a known budget (${Object.keys(DEFAULT_BUDGETS).join(", ")}).`);
  for (const [key, def] of Object.entries(DEFAULT_BUDGETS)) {
    const label = rawBudgets[key] ?? def;
    const bytes = parseSize(label);
    if (bytes === null) { problems.push(`budgets.${key} must be a size like "300 KB" or "1.2 MB".`); continue; }
    budgets[key] = bytes;
    budgetLabels[key] = label;
    if (bytes > parseSize(def)) warnings.push(`Budget ${key} is ${label}, above the default ${def}.`);
  }

  const exclude = raw.sitemap?.exclude ?? [];
  if (!Array.isArray(exclude) || exclude.some((p) => typeof p !== "string" || !p.startsWith("/"))) problems.push('sitemap.exclude must be a list of paths like "/thank-you/".');

  const htmlValidate = raw.htmlValidate ?? [];
  if (!Array.isArray(htmlValidate)) problems.push("htmlValidate must be a list of rule changes.");
  else htmlValidate.forEach((r, i) => {
    if (typeof r?.rule !== "string" || !r.rule) problems.push(`htmlValidate[${i}].rule must name an html-validate rule.`);
    if (!["off", "warn", "error"].includes(r?.level)) problems.push(`htmlValidate[${i}].level must be "off", "warn" or "error".`);
    if (!hasReason(r)) problems.push(`htmlValidate[${i}].reason must say why the rule is changed.`);
  });

  const exceptions = raw.exceptions ?? [];
  if (!Array.isArray(exceptions)) problems.push("exceptions must be a list.");
  else exceptions.forEach((e, i) => {
    if (!CHECK_IDS.includes(e?.check)) problems.push(`exceptions[${i}].check must be one of: ${CHECK_IDS.join(", ")}.`);
    if (typeof e?.page !== "string" || !(e.page === "*" || e.page.startsWith("/"))) problems.push(`exceptions[${i}].page must be a page path like "/about/" or "*" for every page.`);
    if (!hasReason(e)) problems.push(`exceptions[${i}].reason must say why the exception is needed.`);
  });

  if (problems.length) throw new ConfigError(`site-kit.config.js has ${problems.length} problem${problems.length === 1 ? "" : "s"}:\n${problems.map((p) => `  - ${p}`).join("\n")}`);

  return {
    config: {
      site: { url },
      productionBranch,
      previewPort,
      claude: { care },
      flags: { production },
      footer,
      fonts,
      allowedHosts,
      budgets,
      budgetLabels,
      sitemap: { exclude },
      htmlValidate,
      exceptions,
    },
    warnings,
  };
}

export async function loadConfig(root) {
  const file = join(root, "site-kit.config.js");
  if (!existsSync(file)) throw new ConfigError(`No site-kit.config.js in ${root}. Every site needs one; see the site-kit README.`);
  const mod = await import(`${pathToFileURL(file).href}?t=${Date.now()}`);
  return validateConfig(mod.default);
}
```

```js
export function createReview() {
  const items = [];
  return {
    add(item) { items.push(item); },
    reset() { items.length = 0; },
    get items() { return [...items]; },
  };
}

const excerpt = (html) => {
  const text = String(html)
    .replace(/<span class="site-kit-flag__note"[^>]*>.*?<\/span>/g, "")
    .replace(/<[^>]+>/g, "")
    .replace(/\s+/g, " ")
    .trim();
  return text.length > 90 ? `${text.slice(0, 87)}…` : text;
};

const plural = (n, word) => `${n} ${word}${n === 1 ? "" : "s"}`;

export function formatReview(items) {
  const lines = [
    "<!-- Generated by site-kit on every build. Do not edit by hand. -->",
    "# Content review",
    "",
    "This list is generated from the site's content flags. Each item needs to be confirmed, replaced or approved. Reply with the item number and your answer (for example, '7: yes, that is correct'). Numbers can change between drafts, so please quote the page too.",
    "",
    "What the labels mean: **CONFIRM**: please check this is true. **NEW**: new wording to approve. **MADE UP**: a stand-in detail; please supply the real one. **STOCK**: a stock or generated image to replace. **PHOTO**: a photo that's needed.",
    "",
  ];
  if (items.length === 0) return [...lines, "No open items.", ""].join("\n");

  const groups = new Map();
  for (const i of items) {
    const key = JSON.stringify([i.type, i.note, String(i.text)]);
    const group = groups.get(key) ?? { ...i, pages: new Map() };
    if (!group.pages.has(i.url)) group.pages.set(i.url, i.title);
    groups.set(key, group);
  }
  const entries = [...groups.values()];
  const sitewide = entries.filter((g) => g.pages.size > 1);
  const perPage = entries.filter((g) => g.pages.size === 1);

  const counts = {};
  for (const g of entries) counts[g.type] = (counts[g.type] ?? 0) + 1;
  const summary = Object.keys(counts).sort().map((t) => `${counts[t]} ${t}`).join(", ");
  lines.push(`**${plural(entries.length, "item")}**: ${summary}`, "");

  let n = 0;
  const itemLine = (g) => {
    const text = excerpt(g.text);
    return `${++n}. **${g.type}**: ${g.note}${text ? ` — “${text}”` : ""}`;
  };

  const sizes = [...new Set(sitewide.map((g) => g.pages.size))].sort((a, b) => b - a);
  for (const size of sizes) {
    lines.push(`## Sitewide (appears on ${size} pages)`, "");
    for (const g of sitewide.filter((x) => x.pages.size === size)) {
      const line = itemLine(g);
      const indent = " ".repeat(line.indexOf(" ") + 1);
      lines.push(line, `${indent}- Pages: ${[...g.pages.keys()].sort().join(", ")}`);
    }
    lines.push("");
  }

  const byPage = new Map();
  for (const g of perPage) {
    const [[url, title]] = g.pages;
    const page = byPage.get(url) ?? { title, items: [] };
    page.title ||= title;
    page.items.push(g);
    byPage.set(url, page);
  }
  for (const url of [...byPage.keys()].sort()) {
    const { title, items: pageItems } = byPage.get(url);
    lines.push(title ? `## ${title} — \`${url}\`` : `## \`${url}\``, "");
    for (const g of pageItems) lines.push(itemLine(g));
    lines.push("");
  }
  return lines.join("\n");
}

export function assertLaunchReady(items) {
  if (items.length === 0) return;
  const list = items.map((i) => `  ${i.url} — ${i.type}: ${i.note}`).join("\n");
  throw new Error(`Launch blocked: ${plural(items.length, "open review item")}.\n${list}`);
}

export function assertNoPlaceholders(keys) {
  if (keys.length === 0) return;
  throw new Error(`Launch blocked: placeholder facts remain: ${keys.join(", ")}`);
}
```

```js
import { spawnSync } from "node:child_process";
import { mkdtempSync } from "node:fs";
import { createRequire } from "node:module";
import { tmpdir } from "node:os";
import { dirname, join } from "node:path";

// Eleventy's CLI from the site's own node_modules, falling back to the kit's.
export function eleventyBin(root) {
  for (const base of [join(root, "package.json"), import.meta.url]) {
    try {
      return join(dirname(createRequire(base).resolve("@11ty/eleventy/package.json")), "cmd.cjs");
    } catch {
      // try the next location
    }
  }
  throw new Error("Can't find @11ty/eleventy. Run npm install.");
}

export function buildSite(root, { mode = "show", outDir = mkdtempSync(join(tmpdir(), "site-kit-")) } = {}) {
  const r = spawnSync(process.execPath, [eleventyBin(root), "--quiet", `--output=${outDir}`], {
    cwd: root,
    env: { ...process.env, SITE_KIT_FLAGS: mode },
    encoding: "utf8",
  });
  return { ok: r.status === 0, outDir, output: `${r.stdout ?? ""}${r.stderr ?? ""}` };
}
```

```js
import { existsSync, readFileSync, readdirSync, statSync } from "node:fs";
import { join } from "node:path";
import { parseHTML } from "linkedom";

export function fileForUrl(outDir, url) {
  const clean = decodeURIComponent(url.split("#")[0].split("?")[0]);
  return clean.endsWith("/") ? join(outDir, clean, "index.html") : join(outDir, clean);
}

export function builtPages(outDir, prefix = "/") {
  const out = [];
  for (const name of readdirSync(join(outDir, prefix))) {
    const full = join(outDir, prefix, name);
    if (statSync(full).isDirectory()) out.push(...builtPages(outDir, `${prefix}${name}/`));
    else if (name === "index.html") out.push(prefix);
    else if (name.endsWith(".html")) out.push(`${prefix}${name}`);
  }
  return out.sort();
}

export function createPageLoader(outDir) {
  const cache = new Map();
  return (url) => {
    if (!cache.has(url)) {
      const file = fileForUrl(outDir, url);
      if (!existsSync(file)) throw new Error(`Page not built: ${url}`);
      cache.set(url, parseHTML(readFileSync(file, "utf8")).document);
    }
    return cache.get(url);
  };
}

export const isNoindex = (doc) => /noindex/i.test(doc.querySelector('meta[name="robots"]')?.getAttribute("content") ?? "");
```

```js
const TYPES = {
  ".html": "text/html", ".css": "text/css", ".js": "text/javascript", ".json": "application/json",
  ".png": "image/png", ".jpg": "image/jpeg", ".jpeg": "image/jpeg", ".webp": "image/webp", ".avif": "image/avif",
  ".gif": "image/gif", ".svg": "image/svg+xml", ".ico": "image/x-icon", ".xml": "application/xml",
  ".txt": "text/plain", ".pdf": "application/pdf", ".woff2": "font/woff2",
};

export async function serveSite(outDir) {
  const server = createServer((req, res) => {
    const file = fileForUrl(outDir, req.url);
    if (existsSync(file) && statSync(file).isFile()) {
      res.writeHead(200, { "Content-Type": TYPES[extname(file).toLowerCase()] ?? "application/octet-stream" });
      res.end(readFileSync(file));
      return;
    }
    const notFound = join(outDir, "404.html");
    res.writeHead(404, { "Content-Type": "text/html" });
    res.end(existsSync(notFound) ? readFileSync(notFound) : "Not found");
  });
  await new Promise((resolve) => server.listen(0, "127.0.0.1", resolve));
  return { url: `http://127.0.0.1:${server.address().port}`, close: () => new Promise((resolve) => server.close(resolve)) };
}
```

```js
const plural = (n, word) => `${n} ${word}${n === 1 ? "" : "s"}`;

export function applyExceptions(problems, exceptions) {
  const failures = [];
  const excepted = [];
  for (const p of problems) {
    const match = exceptions.some((e) => e.check === p.check && (e.page === "*" || e.page === p.page));
    (match ? excepted : failures).push(p);
  }
  return { failures, excepted };
}

export function summarize(failures, pageCount, siteTestsOk) {
  if (!failures.length) return siteTestsOk ? `✔ All checks passed on ${plural(pageCount, "page")}.` : "✖ Site tests failed";
  const pages = new Set(failures.map((f) => f.page)).size;
  const checks = [...new Set(failures.map((f) => f.check))].sort().join(", ");
  return `✖ ${plural(failures.length, "problem")} on ${plural(pages, "page")} (${checks})${siteTestsOk ? "" : ", and site tests failed"}`;
}

export function formatReport({ failures, warnings, exceptions, pageCount, siteTests }) {
  const lines = [summarize(failures, pageCount, siteTests.ok), ""];
  const byPage = new Map();
  for (const f of failures) byPage.set(f.page, [...(byPage.get(f.page) ?? []), f]);
  for (const page of [...byPage.keys()].sort()) {
    lines.push(page);
    for (const f of byPage.get(page)) lines.push(`  [${f.check}] ${f.message}`);
    lines.push("");
  }
  if (siteTests.ran && !siteTests.ok) lines.push("Site tests (tests/ folder) failed:", siteTests.output.trim(), "");
  if (warnings.length) lines.push("Warnings:", ...warnings.map((w) => `  - ${w}`), "");
  if (exceptions.length) lines.push("Exceptions in use:", ...exceptions.map((e) => `  - ${e.check} on ${e.page}: ${e.reason}`), "");
  return lines.join("\n");
}
```

```js
import { isNoindex } from "../runner/pages.js";

export const id = "sitemap";
export const browser = false;

export async function run({ pages, loadPage, outDir, config }) {
  const file = join(outDir, "sitemap.xml");
  if (!existsSync(file)) return [{ page: "(site)", message: "There is no sitemap.xml. Search engines use it to find every page." }];
  const problems = [];
  const site = (message) => problems.push({ page: "(site)", message });
  const exclude = config.sitemap.exclude;
  const locs = [...readFileSync(file, "utf8").matchAll(/<loc>\s*([^<\s]+)\s*<\/loc>/g)].map((m) => m[1]);
  const listed = new Set();
  for (const loc of locs) {
    if (!loc.startsWith(`${config.site.url}/`)) { site(`sitemap.xml lists ${loc}, which isn't on ${config.site.url}.`); continue; }
    const path = loc.slice(config.site.url.length);
    if (listed.has(path)) { site(`sitemap.xml lists ${path} more than once.`); continue; }
    listed.add(path);
    if (!pages.includes(path)) site(`sitemap.xml lists ${path}, which doesn't exist.`);
    else if (isNoindex(loadPage(path))) site(`sitemap.xml lists ${path}, which is marked noindex.`);
    else if (exclude.includes(path)) site(`sitemap.xml lists ${path}, which site-kit.config.js excludes.`);
  }
  for (const page of pages) {
    if (exclude.includes(page) || isNoindex(loadPage(page))) continue;
    if (!listed.has(page)) problems.push({ page, message: "This page is missing from sitemap.xml." });
  }
  return problems;
}
```

```js
function walk(dir) {
  const out = [];
  for (const name of readdirSync(dir)) {
    const full = join(dir, name);
    if (statSync(full).isDirectory()) out.push(...walk(full));
    else out.push(full);

export async function run({ pages, loadPage, fileForUrl, outDir, config }) {
  const { budgets, budgetLabels } = config;
  const problems = [];

    const doc = loadPage(page);
    const p = (message) => problems.push({ page, message });
    const htmlBytes = statSync(fileForUrl(page)).size;

    doc.querySelectorAll("video[autoplay], audio[autoplay]").forEach((m) => p(`A <${m.localName}> autoplays; let visitors start media themselves.`));
    for (const link of doc.querySelectorAll('link[rel="stylesheet"][href*="fonts.googleapis.com"]')) {
      for (const m of link.getAttribute("href").matchAll(/family=([^:&]+)/g)) {
        const family = decodeURIComponent(m[1]).replace(/\+/g, " ");
        if (!config.fonts.includes(family)) p(`Loads the font "${family}", which isn't in site-kit.config.js. Use the site's design fonts.`);
      }
    }
    let total = htmlBytes;
    for (const src of local) {
      const file = fileForUrl(src);
      if (existsSync(file) && statSync(file).isFile()) total += statSync(file).size;
    }
    if (total > budgets.pageTotal) p(`The page weight is ${fmt(total)} (budget ${budgetLabels.pageTotal}); compress or resize images.`);
  }
  let css = 0;
  let js = 0;
  for (const file of walk(outDir)) {
    const ext = extname(file).toLowerCase();
    const rel = file.slice(outDir.length).replace(/\\/g, "/").replace(/^\/?/, "/");
    if (ext === ".css") css += statSync(file).size;
    if (ext === ".js") js += statSync(file).size;
    if (!ANY_IMAGE.includes(ext)) continue;
    if (!WEB_IMAGES.includes(ext)) problems.push({ page: "(site)", message: `${rel}: ${ext} isn't a web image format; convert it with site-kit add-photo.` });

  }
  if (css > budgets.cssTotal) problems.push({ page: "(site)", message: `CSS totals ${fmt(css)} (budget ${budgetLabels.cssTotal}).` });
  if (js > budgets.jsTotal) problems.push({ page: "(site)", message: `JavaScript totals ${fmt(js)} (budget ${budgetLabels.jsTotal}).` });
  return problems;
```

```js
import { existsSync, readFileSync } from "node:fs";
import { join } from "node:path";

export const id = "csp";
export const browser = false;

const DIRECTIVES = { script: "script-src", stylesheet: "style-src", iframe: "frame-src", img: "img-src", form: "form-action" };

export function parseCsp(text) {
  return text.split(/\r?\n/)
    .map((line) => /^\s*Content-Security-Policy:\s*(.+)$/i.exec(line)?.[1])
    .filter(Boolean)
    .map((value) => Object.fromEntries(value.split(";").map((d) => d.trim().split(/\s+/)).filter((d) => d[0]).map(([name, ...sources]) => [name.toLowerCase(), sources])));
}

export function permits(policy, directive, host) {
  let sources = policy[directive];
  if (!sources && directive === "frame-src") sources = policy["child-src"];
  if (!sources && directive !== "form-action") sources = policy["default-src"];
  if (!sources) return true;
  return sources.some((s) => s === "*" || s === "https:" || s === host || s === `https://${host}` ||
    (s.startsWith("https://*.") && host.endsWith(s.slice("https://*".length))) ||
    (s.startsWith("*.") && host.endsWith(s.slice(1))));
}

export async function run({ pages, loadPage, outDir, config }) {
  const problems = [];
  for (const page of pages) {
    const doc = loadPage(page);
    for (const s of doc.querySelectorAll("script:not([src])")) {
      if (s.getAttribute("type") !== "application/ld+json") problems.push({ page, message: "Has an inline <script>. Move the code into a .js file so the Content Security Policy can block injected scripts." });
    }
    for (const el of doc.querySelectorAll("*")) {
      for (const { name } of el.attributes) {
        if (/^on[a-z]+$/.test(name)) problems.push({ page, message: `<${el.localName} ${name}> runs inline code. Attach the handler from a .js file instead.` });
      }
    }
  }
  const file = join(outDir, "_headers");
  if (!existsSync(file)) return problems;
  const policies = parseCsp(readFileSync(file, "utf8"));
  if (!policies.length) {
    problems.push({ page: "(site)", message: "_headers has no Content-Security-Policy." });
    return problems;
  }
  for (const policy of policies) {
    for (const { host, types } of config.allowedHosts) {
      for (const type of types) {
        const directive = DIRECTIVES[type];
        if (!permits(policy, directive, host)) problems.push({ page: "(site)", message: `The Content-Security-Policy in _headers doesn't allow ${host} for ${directive}, so the approved ${type} would be blocked on the live site.` });
      }
    }
  }
  return problems;
}
```

```js
import { spawnSync } from "node:child_process";
import { existsSync, readdirSync, rmSync, statSync } from "node:fs";
import { join } from "node:path";
import { loadConfig } from "../config.js";
import { buildSite } from "../runner/build.js";
import { runChecks } from "../runner/run.js";
import { applyExceptions, formatReport, summarize } from "../runner/results.js";

function siteTestFiles(root) {
  const dir = join(root, "tests");
  if (!existsSync(dir)) return [];
  const walk = (d) => readdirSync(d).flatMap((name) => {
    const full = join(d, name);
    return statSync(full).isDirectory() ? walk(full) : name.endsWith(".test.js") ? [full] : [];
  });
  return walk(dir);
}

export async function runTest({ root, siteTests = true }) {
  let loaded;
  try {
    loaded = await loadConfig(root);
  } catch (err) {
    return { ok: false, report: err.message, json: { ok: false, summary: err.message } };
  }
  const { config, warnings } = loaded;
  const build = buildSite(root, { mode: "show" });
  try {
    if (!build.ok) {
      const report = `✖ The site didn't build:\n${build.output.trim()}`;
      return { ok: false, report, json: { ok: false, summary: "The site didn't build" } };
    }
    const { problems, pageCount } = await runChecks({ root, config, outDir: build.outDir });
    const { failures, excepted } = applyExceptions(problems, config.exceptions);
    const files = siteTests ? siteTestFiles(root) : [];
    const site = { ran: files.length > 0, ok: true, output: "" };
    if (files.length) {
      const r = spawnSync(process.execPath, ["--test", ...files], { cwd: root, env: { ...process.env, SITE_KIT_OUT_DIR: build.outDir }, encoding: "utf8" });
      site.ok = r.status === 0;
      site.output = `${r.stdout ?? ""}${r.stderr ?? ""}`;
    }
    const ok = failures.length === 0 && site.ok;
    const report = formatReport({ failures, warnings, exceptions: config.exceptions, pageCount, siteTests: site });
    return {
      ok,
      report,
      json: { ok, summary: summarize(failures, pageCount, site.ok), pageCount, failures, excepted, warnings, exceptions: config.exceptions, siteTests: { ran: site.ran, ok: site.ok } },
    };
  } finally {
    rmSync(build.outDir, { recursive: true, force: true });
  }
```

```js
import { existsSync, mkdirSync, statSync } from "node:fs";
import { join } from "node:path";
import sharp from "sharp";
import { loadConfig } from "../config.js";

const MAX_SIDE = 1600;

export async function addPhoto({ root, input, name: rawName }) {
  if (!input || !rawName) return { ok: false, message: "Usage: site-kit add-photo <path-to-photo> <name>   (e.g. front-porch)" };
  if (!existsSync(input)) return { ok: false, message: `Can't find the photo: ${input}` };
  const { config } = await loadConfig(root);
  const budget = config.budgets.imageFile;
  const name = rawName.toLowerCase().replace(/\.[a-z0-9]+$/, "").replace(/[^a-z0-9]+/g, "-").replace(/^-|-$/g, "");
  const dir = join(root, "src", "assets", "img");
  const out = join(dir, `${name}.jpg`);
  if (existsSync(out)) return { ok: false, message: `src/assets/img/${name}.jpg already exists. Choose a different name.` };
  try {
    await sharp(input).metadata();
  } catch {
    return { ok: false, message: "That file isn't a photo format site-kit can read. Save or export it as a JPEG first (iPhone HEIC photos included)." };
  }
  mkdirSync(dir, { recursive: true });
  let quality = 78;
  let info;
  do {
    info = await sharp(input)
      .rotate()
      .resize({ width: MAX_SIDE, height: MAX_SIDE, fit: "inside", withoutEnlargement: true })
      .jpeg({ quality, mozjpeg: true })
      .toFile(out);
    quality -= 8;
  } while (statSync(out).size > budget && quality >= 46);
  const kb = Math.round(statSync(out).size / 1024);
  if (statSync(out).size > budget) return { ok: false, message: `Saved src/assets/img/${name}.jpg, but it's still ${kb} KB (budget ${config.budgetLabels.imageFile}). A developer should look at it.` };
  const tag = `<img src="/assets/img/${name}.jpg" width="${info.width}" height="${info.height}" alt="DESCRIBE THE PHOTO" loading="lazy">`;
  return { ok: true, message: `Saved src/assets/img/${name}.jpg (${info.width}×${info.height}, ${kb} KB)`, tag };
}
```

```markdown
# Working on this site (site-kit)

These rules apply to every site that uses site-kit. The site's own `CLAUDE.md` and `SITE.md` add its
details and may narrow these rules, never loosen them.

## Roles

- **Content editors** write and edit copy, add pages and posts, and adjust presentation within the
  design system. They focus on content and shouldn't need to read code, test output or file paths.
- **Developers** own the code, configuration, tests, third-party services, hosting and the site-kit
  version, and review and merge every change.

## Working with content editors

- Use plain language. Describe changes by where they appear ("the second paragraph on the About
  page"), not by file. Share code or command output only when asked.
- Show every change: the local preview (the preview server in `.claude/launch.json`), or the preview
  deployment link once pushed.
- Make one change at a time and confirm it looks right before moving on.
- If checks fail, explain the problem in one or two sentences and fix the content.
- If a request is developer-only (see below), say so and offer what you can do now.

## Push back, then offer an alternative

Decline requests that would harm accessibility, performance, privacy or honesty, kindly and clearly,
and always propose a version that achieves the goal. Never make an exception "just this once".

| Request | Why not | Offer instead |
|---|---|---|
| Pale or low-contrast text, text over a busy photo | Fails WCAG contrast; hard to read | A palette colour that passes, or text on a solid panel |
| Smaller text to fit more in | Body text stays at least 16px | Shorter copy, or more sections |
| Keyword-filled alt text, hidden text, keyword-stuffed headings | Hurts screen-reader users; search engines penalise it | Accurate alt text, a clear heading order, keywords used naturally in the copy |
| Autoplaying media, carousels, pop-ups, animated banners | Distracting, inaccessible, slow | A static image with a link; media the visitor starts |
| A chat widget, tracking pixel, analytics or other embed | Slows every page, privacy risk, blocked by the security headers | Developer-only; a phone or contact link meanwhile |
| A large photo straight from a camera or stock site | Slow on phones | `npx site-kit add-photo "<file>" <name>` first |
| "Click here" or "Read more" links | Meaningless out of context | Link text that says where it goes |
| New colours or fonts | Breaks the design and may fail contrast | The existing design tokens and fonts |

## Flags

Unconfirmed or placeholder content is wrapped in a flag until someone with authority confirms it:
`{% flag "CONFIRM", "What needs checking" %}the text{% endflag %}`. Types: `CONFIRM` (needs checking),
`NEW` (new copy to approve), `MADE UP` (a stand-in detail), `STOCK` (generic image or text). A missing
photo is `{% photo "What the photo should show", "4/3" %}` (ratios: 1/1, 4/3, 3/2, 16/9, 21/9, 3/4,
2/3, 4/5). Flags are highlighted in local previews, hidden on preview deployments, and listed in
`CONTENT-REVIEW.md` (`npx site-kit review`). Never remove a flag without knowing who confirmed it.

## How sites are built

- Pages are `src/<page>/index.njk` with a layout, a `title` and a unique `description` (50–160
  characters) in the front matter. Copy the structure of an existing page.
- Shared facts (phone, address, menu) live in the site's data files; never hard-code them in a page.
- One `h1` per page; headings in order without skipping levels.
- Use the design tokens and existing classes; no one-off colours or inline styles.
- Photos: `npx site-kit add-photo "<file>" <name>`, then use the `<img>` tag it prints and write
  accurate alt text. Images below the first screen keep `loading="lazy"`.
- If a change adds video, audio, a form, a map or third-party content, update the site's
  accessibility page in the same change.

## Checks

`npx site-kit test` builds the site and checks every page: accessibility, valid HTML, links,
structure, consistency, performance, approved services, security headers, readability, the sitemap
and sensitive form fields. New pages are covered automatically.

- Run it before calling any change done. Everything must pass.
- Never weaken, skip or edit tests, budgets, exceptions or protected files to make a check pass. If a
  check seems wrong, explain why and leave it for a developer.
- When returning to a site after time away, run `npx site-kit doctor` first.

## Publishing

Never commit to or push the production branch. Work on a branch named `content/<short-description>`,
commit with a plain-English message, and use `/send-for-review` to open a pull request for a
developer to review. Share the preview deployment link it gives you.

## Developer-only

Third-party services, analytics, forms and email, hosting and domains, packages, the site-kit
version, tests, `site-kit.config.js`, and the protected files listed in `.claude/settings.json`.

## Cross-platform

Sites are edited on Windows and macOS. Use Node scripts and `npx site-kit …` commands; no shell-only
or platform-only tools.
```

```js
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";

const TEMPLATES = fileURLToPath(new URL("../../templates/", import.meta.url));
export const KIT_VERSION = JSON.parse(readFileSync(new URL("../../package.json", import.meta.url), "utf8")).version;

const MANAGED = [
  { from: "workflow.yml", to: ".github/workflows/site-kit.yml", header: "#" },
  { from: "settings.json", to: ".claude/settings.json" },
  { from: "launch.json", to: ".claude/launch.json" },
  { from: "gitattributes", to: ".gitattributes", header: "#" },
  { from: "skills/new-page/SKILL.md", to: ".claude/skills/new-page/SKILL.md", header: "md" },
  { from: "skills/new-blog-post/SKILL.md", to: ".claude/skills/new-blog-post/SKILL.md", header: "md" },
  { from: "skills/send-for-review/SKILL.md", to: ".claude/skills/send-for-review/SKILL.md", header: "md" },
];

const NOTE = `Managed by site-kit ${KIT_VERSION}. Don't edit this copy: change site-kit and run \`site-kit sync\`.`;

function render(text, vars) {
  return text.replace(/\{\{(\w+)\}\}/g, (match, key) => {
    if (!(key in vars)) throw new Error(`Unknown template variable ${match}`);
    return String(vars[key]);
  });
}

function withHeader(text, kind) {
  if (kind === "#") return `# ${NOTE}\n${text}`;
  if (kind === "md") {
    const front = /^---\n[\s\S]*?\n---\n/.exec(text);
    return front ? `${front[0]}\n<!-- ${NOTE} -->\n${text.slice(front[0].length)}` : `<!-- ${NOTE} -->\n${text}`;
  }
  return text;
}

export function claudeImports(config) {
  return ["@node_modules/site-kit/CLAUDE.base.md", ...(config.claude.care ? ["@node_modules/site-kit/CLAUDE.care.md"] : []), "@SITE.md"];
}

function desiredFiles(config) {
  const vars = { previewPort: config.previewPort, productionBranch: config.productionBranch, version: KIT_VERSION };
  return MANAGED.map(({ from, to, header }) => [to, withHeader(render(readFileSync(join(TEMPLATES, from), "utf8"), vars), header)]);
}

export function syncFiles(root, config, { check = false } = {}) {
  const changes = [];
  const write = (rel, content, action) => {
    changes.push({ path: rel, action });
    if (check) return;
    const file = join(root, rel);
    mkdirSync(dirname(file), { recursive: true });
    writeFileSync(file, content);
  };
  for (const [rel, content] of desiredFiles(config)) {
    const file = join(root, rel);
    const current = existsSync(file) ? readFileSync(file, "utf8").replace(/\r\n/g, "\n") : null;
    if (current !== content) write(rel, content, current === null ? "create" : "update");
  }
  const imports = claudeImports(config);
  const claudeFile = join(root, "CLAUDE.md");
  if (!existsSync(claudeFile)) {
    write("CLAUDE.md", `${imports.join("\n")}\n\n# Site guidance\n\nSite-specific guidance for Claude goes here. Shared rules come from the imports above.\n`, "create");
  } else {
    const current = readFileSync(claudeFile, "utf8").replace(/\r\n/g, "\n");
    const lines = current.split("\n");
    if (!imports.every((i) => lines.includes(i))) {
      const rest = lines.filter((l) => !imports.includes(l)).join("\n").replace(/^\n+/, "");
      write("CLAUDE.md", `${imports.join("\n")}\n\n${rest}`, "update");
    }
  }
  if (!existsSync(join(root, "SITE.md"))) write("SITE.md", readFileSync(join(TEMPLATES, "SITE.md"), "utf8"), "create");
  return changes;
}
```

```js
  if (checkLatest) {
    const r = spawnSync("git", ["ls-remote", "--tags", "--refs", REPO], { encoding: "utf8", timeout: 10000 });
    if (r.status === 0) latest = r.stdout.split("\n").map((l) => /refs\/tags\/v(\d+\.\d+\.\d+)$/.exec(l)?.[1]).filter(Boolean).sort(compareVersions).at(-1) ?? null;
  }
  if (!latest) add("OK", `site-kit ${KIT_VERSION}${checkLatest ? " (couldn't check for a newer release)" : ""}`);
  else if (compareVersions(KIT_VERSION, latest) < 0) add("WARN", `site-kit ${KIT_VERSION} is installed; ${latest} is available. See the CHANGELOG before upgrading.`);
  else add("OK", `site-kit ${KIT_VERSION} (latest)`);

  const nodeMajor = Number(process.versions.node.split(".")[0]);
  add(nodeMajor >= 22 ? "OK" : "FAIL", `Node ${process.versions.node}${nodeMajor >= 22 ? "" : " (site-kit needs 22 or newer)"}`);

  let loaded;
  try {
    loaded = await loadConfig(root);
  } catch (err) {
    add("FAIL", err.message);
    return { lines, code: 1 };
  }
  const { config, warnings } = loaded;

  const drift = syncFiles(root, config, { check: true });
  if (drift.length) add("WARN", `${drift.length} managed file${drift.length === 1 ? "" : "s"} out of date (${drift.map((d) => d.path).join(", ")}); run \`npx site-kit sync\``);
  else add("OK", "Managed files are up to date");

  const lockFile = join(root, "package-lock.json");
  if (!existsSync(lockFile)) add("WARN", "No package-lock.json; run npm install with npm 10 and commit it");
  else {
    const lock = JSON.parse(readFileSync(lockFile, "utf8"));
    const bad = Object.entries(lock.packages ?? {}).filter(([, v]) => v.os && !v.optional && !v.devOptional && !v.peer).map(([k]) => k);
    if (bad.length) add("WARN", `package-lock.json lists platform-only packages as required (${bad.join(", ")}); regenerate it with npm 10`);
    else add("OK", "package-lock.json installs on every platform");
  }

  const branch = git(root, ["branch", "--show-current"]);
  if (branch.status === 0) {
    const dirty = git(root, ["status", "--porcelain"]).stdout.trim().split("\n").filter(Boolean).length;
    add(dirty ? "WARN" : "OK", `Branch ${branch.stdout.trim() || "(none)"}${dirty ? `, ${dirty} uncommitted change${dirty === 1 ? "" : "s"}` : ", no uncommitted changes"}`);
    const behind = git(root, ["rev-list", "--count", `HEAD..origin/${config.productionBranch}`]);
    if (behind.status === 0 && Number(behind.stdout.trim()) > 0) add("WARN", `${behind.stdout.trim()} commits behind origin/${config.productionBranch} (as of the last git fetch)`);
  }

  const test = await runTest({ root });
  add(test.ok ? "OK" : "FAIL", test.json.summary ?? "Checks didn't run");

  const reviewFile = join(root, "CONTENT-REVIEW.md");
  const count = existsSync(reviewFile) ? /\*\*(\d+) items?\*\*: (.*)/.exec(readFileSync(reviewFile, "utf8")) : null;
  if (count) add("WARN", `${count[1]} open review item${count[1] === "1" ? "" : "s"} (${count[2]}); see CONTENT-REVIEW.md`);
  else add("OK", "No open review items");

  for (const w of warnings) add("WARN", w);
  for (const e of config.exceptions) add("WARN", `Exception: ${e.check} on ${e.page}: ${e.reason}`);

  const siteMd = join(root, "SITE.md");
  if (!existsSync(siteMd)) add("WARN", "No SITE.md; run `npx site-kit sync` and fill it in");
  else {
    const newest = newestDecision(readFileSync(siteMd, "utf8"));
    if (!newest) add("WARN", "SITE.md has no dated decisions yet");
    else {
      const days = Math.round((now - new Date(`${newest}T00:00:00Z`)) / 86400000);
      add(days > 180 ? "WARN" : "OK", `SITE.md: newest decision ${newest} (${days} days ago)${days > 180 ? "; check it's still current" : ""}`);
    }
  }

  return { lines, code: lines.some((l) => l.level === "FAIL") ? 1 : 0 };
}
```

````markdown
# site-kit

Checks, content-review flags and Claude Code rules for Eleventy marketing sites. One kit keeps every
site to the same standard for accessibility, performance and honest content, and makes a site that
hasn't been touched for months quick to pick up again.

## Install

In an Eleventy 3 site, with npm 10:

```bash
npx -y -p npm@10.9.9 npm install --save-dev github:scottgroup-sites/site-kit#v1.0.0
```

Add `"test": "site-kit test"` to the site's `package.json` scripts.

## Configure

Create `site-kit.config.js` (every setting is validated; anything loosened needs a `reason`):

```js
export default {
  site: { url: "https://www.example.com" },
  productionBranch: "main",
  previewPort: 8080,
  claude: { care: false },
  flags: { production: "fail" }, // "fail" before launch, "hide" once live
  footer: { text: ["(555) 010-0100"], links: ["/accessibility/", "/privacy/"] },
  fonts: [],
  allowedHosts: [{ host: "www.google.com", types: ["iframe"], reason: "Map on the contact page" }],
  sitemap: { exclude: ["/thank-you/"] },
};
```

Add the plugin to `eleventy.config.js`:

```js
import siteKit from "site-kit/eleventy";
import kitConfig from "./site-kit.config.js";

export default function (eleventyConfig) {
  eleventyConfig.addPlugin(siteKit, { config: kitConfig, titleSuffix: " — Example", placeholders: [] });
}
```

Then run `npx site-kit sync` and commit the files it creates.

## Commands

| Command | What it does |
|---|---|
| `npx site-kit test [--json]` | Build the site and check every page |
| `npx site-kit review` | Write `CONTENT-REVIEW.md` from the content flags |
| `npx site-kit add-photo "<file>" <name>` | Resize, compress and strip metadata from a photo; print its `<img>` tag |
| `npx site-kit sync [--check]` | Update the files site-kit manages in the repo |
| `npx site-kit doctor` | Report the site's status; run it first when returning to a site |

## Checks

`a11y`, `html`, `links`, `structure`, `consistency`, `performance`, `hosts`, `csp`, `readability`,
`sitemap`, `sensitive-fields`. See the design spec in `docs/superpowers/specs/` for what each enforces.
Site-specific tests in the site's `tests/` folder run too, with helpers from `site-kit`:
`builtPages`, `loadPage`, `fileForUrl`, `serveSite`, `launchBrowser`, `buildSite`.

## Content flags

`{% flag "CONFIRM", "What needs checking" %}text{% endflag %}` and `{% photo "description", "4/3" %}`.
Flags show locally, are hidden on preview deployments, and on the production branch either hide or
fail the build (`flags.production`). Set `SITE_KIT_FLAGS` to `show`, `hide` or `fail` to override.

## Branch protection

After the first pull request has run the workflow, require its checks:

```bash
gh api -X PATCH repos/OWNER/REPO/branches/main/protection/required_status_checks -F strict=false -f 'contexts[]=site-kit (ubuntu-latest)' -f 'contexts[]=site-kit (windows-latest)' -f 'contexts[]=Cloudflare Pages'
```

## Upgrading a site

On a branch: change the tag in `package.json`, `npm install` with npm 10, `npx site-kit sync`, fix
what the checks find, and merge once CI passes. Read the CHANGELOG first.

## Contributing

This repository is public. Never add names of people, clients or businesses, real domains, phone
numbers, keys or IDs. Examples use `example.com` and `(555) 01xx` numbers. Guidance describes roles,
not individuals.
````
